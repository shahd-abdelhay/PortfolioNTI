# Shahd M. Abdelhay — AI Portfolio Website

A responsive, professional one-page portfolio draft based on the structure of the reference PDF:
About, Education/Journey, Skills, Services/Capabilities, Selected Work/Case Studies, and Contact.

## Run
Open `index.html` in a browser.

## Customize
- Replace `assets/profile.jpg` with a different professional photo if desired.
- Replace the placeholder email in `index.html`.
- Add GitHub / LinkedIn links in the Contact section.
- Add project screenshots inside the project cards when available.

The visual direction is intentionally different from the reference: dark navy, cyan/violet accents, glass cards, large typography, and a technical AI aesthetic.
